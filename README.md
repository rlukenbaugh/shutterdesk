# ShutterDesk v1.0.0 — Windows Installer Kit

Generated by ShutterDesk Windows Builder.

## Where ShutterDesk Is Installed on Windows
- **Executable:** `%LOCALAPPDATA%\Programs\ShutterDesk\ShutterDesk.exe`
- **Start Menu Shortcut:** `%APPDATA%\Microsoft\Windows\Start Menu\Programs\ShutterDesk.lnk`

Once installed, press the **Windows Start** key and type **ShutterDesk** to launch or bring it to the foreground.

## Option 1: Full Electron + NSIS Windows Installer (`ShutterDesk-Setup-1.0.0.exe`)
Includes full screenshot capture, multi-display/window picker, screen video recording, system tray, single-instance foreground restore, and Start Menu shortcuts.

1. Unzip this folder on Windows 10/11.
2. Double-click **`BUILD-WINDOWS-EXE.bat`** (requires Node.js LTS).
3. Run the generated `dist\ShutterDesk-Setup-1.0.0.exe` installer.

## Option 2: Zero-Dependency Native Windows Installer (No Node.js Needed)
Compiles and installs a native WinForms/GDI+ screenshot & region-snip executable directly to `%LOCALAPPDATA%\Programs\ShutterDesk`, creates Start Menu & Desktop shortcuts, and launches immediately.

1. Open the `native-csharp` folder.
2. Double-click **`INSTALL-NATIVE-SHUTTERDESK.bat`**.

## Already Compiled? Register Start Menu Shortcut in 1 Click
If you already compiled `ShutterDesk.exe` and it does not appear when searching in Windows Start, double-click **`Fix-Start-Menu-Shortcut.bat`** in this folder.

## Option 3: Build in the Cloud with GitHub Actions
Push this folder to GitHub and run the **Build Windows Installer (.exe)** workflow to download `ShutterDesk-Setup-1.0.0.exe` from GitHub Artifacts.
